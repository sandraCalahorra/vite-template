### npm

- Run `npm install` to install dependencies
- Run `npm run dev` to compile assets

### yarn

- Run `yarn install` to install dependencies
- Run `yarn run dev` to compile assets

### To start in DEV mode
- Run `php artisan serve` to start the server
- Run `npm run watch` to set the aplication in watch mode, meaning every change will aplly on refresh page
- Run `npm run hot` to set the aplication in hot reload, meaning every change will aplly on saving the changes

If you get an 500 internal server error and the `.env` is created, that means you need an encryption key for the `.env`
- Run `php artisan key:generate` to generate a encryption key for the project

- Run `php artisan jwt:secret` to generate a secret key in the `.env`. This is for authentication with JWT.
- Remember to add `JWT_TTL = 1440`  in the `.env`. This is for indicates the life time of the session token with JWT, in this case `1440` represents `24 hours` in minutes.

### Deploy
To deploy in Plesk, follow these steps:

1. Execute the following command in your development environment to generate the JS and CSS files for your server:
```bash
npm run production
```

> Note: The generated JS and CSS files can be found in the public folder. On your server, you can manually replace the existing JS and CSS files with the new ones generated by the aforementioned command.

2. Access the SSH extension in your Plesk control panel.
3. Navigate to your website domain or subdomain:
```bash
cd ..
cd var/www/vhost/{yourDomainName}/{yourSubdomainName}
```

4. Install dependencies whenever the code changes and refresh the old dependencies:
```bash
export PATH=/opt/plesk/node/20/bin:$PATH && npm install
export PATH=/opt/plesk/php/8.1/bin:$PATH && composer install
export PATH=/opt/plesk/php/8.1/bin:$PATH && composer dump-autoload -o
```
5. To clear the cache:
```bash
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan cache:clear
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan config:clear
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan route:clear
```
6. For better performance, cache the config and route files:
```bash
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan config:cache
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan route:cache
```
7. If there are any changes in the database, run the migrate command:
```bash
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan migrate
```
8. If you want to run the seeder to populate data in the database, run the following command:
```bash
export PATH=/opt/plesk/php/8.1/bin:$PATH && php artisan db:seed
```

> Note: Adjust the paths and version numbers according to your specific setup.

> Note about the package.json: If there's any conflict on instalation remove the node-sass dependency
